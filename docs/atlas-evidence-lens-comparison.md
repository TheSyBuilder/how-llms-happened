# Evidence lenses: static comparison contract

**Status:** accepted bounded static comparator at `/atlas/lenses/`. This is the expert companion to the four [connection studies](atlas-neighborhood-comparison.md), with a complete incident list and source-located evidence in every case. Native anchors and disclosures expose precomputed intersections; no client filters or measured learning benefit are claimed.

## Design and interaction brief

The exact learning objective is to apply evidence class, causal permission and connection type independently, explain why each record remains or is excluded, and distinguish local matches from matches elsewhere in the corpus. The expert must locate a retained record's version-bound evidence and explain what a zero result does and does not establish.

Definitions alone describe the fields separately. A static comparison can already teach their intersection: the same focused work and complete incident list remain fixed while eight named lenses expose different subsets. That is the complete competitor for any later filter, not evidence that controls would improve learning. The reader follows a row to its native disclosure, checks the exact constraints, reads retained IDs and excluded-field explanations, then opens the original evidence. No recomputation, animation or inferred path is needed.

The north star is the project's annotated research ledger. Existing atlas and neighborhood pages own typography, warm canvas, border geometry, source-link colors and evidence density. The count table acts as a balance sheet: local matches plus local exclusions equal all incident records; local matches plus matching records elsewhere equal global matches. No new expressive donor, imagery or motion is introduced. [WAI's caption and summary guidance](https://www.w3.org/WAI/tutorials/tables/caption-summary/) and [table-header guidance](https://www.w3.org/WAI/tutorials/tables/irregular/), accessed 2026-10-12, inform captions, explicit row/column associations and nearby scope explanations. The earlier atlas inspiration audit remains applicable; no new direct usability audit is claimed.

Eight lenses hold one or more fields constant: all records; documented evidence; inherited mechanism; editorial synthesis; causal prohibition; documented plus prohibited; editorial plus prohibited; and documented plus qualified plus `builds-on`. Multiple constraints intersect with AND. Omitted fields accept all admitted values. The raw values stay visible in each disclosure; shorthand in the table is not a certainty or importance ranking.

Beginner mode retains named prediction/reveal studies and their complete lists. This expert companion instead requires field reconstruction, excluded-record auditing, count accounting and exact locators. Each case links back to both existing modes at the same case anchor. No filter wall is added to beginner mode, and no control state is carried across modes.

At 320 CSS pixels the four-column count table keeps captions, row labels and all three scopes. Detailed constraints and count ledgers stack; long IDs wrap. Use native links and details, visible focus, adequate link targets, and no horizontal page overflow. Keyboard, JavaScript-off, graphics-hidden, reduced-motion, forced-color and print treatments retain all tasks and evidence. Print exposes disclosures. Zero client JavaScript, no remote requests and the existing 512 KiB gzip HTML budget apply. Human screen-reader and learner testing remain separate from automated checks.

## Grounded tasks and material errors

|---|---|---|
| Markov: compare documented with editorial-plus-prohibited. Explain a local zero result. | The sole incident bridge is editorial and prohibits causal language. No documented match here does not prove the historical absence of influence. Matching documented records elsewhere are outside this neighborhood. | Turning missing reviewed evidence into proof of no influence, or adding outside records to the local list. |
| Elman: reconstruct the documented/qualified/`builds-on` intersection and audit what is excluded. | It retains the Miikkulainen–Dyer and Mikolov records. The Bengio `combines` and original-LSTM `addresses` records fail the type constraint, despite matching the other two fields. Every record still has its original evidence. | Treating discarded records as false or less important, merging distinct connections, or transferring training/results through a retained architectural link. |
| Graves: compare documented with documented-plus-prohibited, then the three-field lens. | The Bahdanau comparison survives the first intersection; its documented class coexists with prohibited causality. It fails the three-field lens on both permission and connection type. Source scope remains Bahdanau v1 p. 9 / v7 p. 8, section 6.1. | Conflating documented evidence with causal permission, reporting only one failed field, or replacing the version-specific locators. |
| Cho: compare documented with editorial-plus-prohibited; then inspect inherited mechanism. | The Sutskever parallel-development record is editorial/prohibited. An inherited-mechanism zero in this neighborhood does not mean the whole corpus has zero such records. Public posting order does not establish conception priority. | Reading a zero as no influence, treating a count as a ranking, or transferring v1 concurrency wording to later versions. |

The complete count and record lists are computed from the admitted corpus, not authored result fixtures. Each excluded entry names every failed constraint and preserves a link to its complete evidence. Each empty subset prints the active constraints and offers the all-records lens and complete incident list. It says “No matching incident records,” never “No influence.” Records elsewhere can be inspected in the unchanged global register; they never become local neighbors.

## Projection and acceptance

The lossless projection accepts optional evidence, permission and type constraints and an optional focus work. Global scope is explicit when no focus is supplied. Validate constraint names and values against the corpus schema; malformed constraints fail rather than silently broadening results. Valid values remain valid even when the corpus or neighborhood has no match. Missing focused works fail explicitly; an admitted isolated work yields a zero incident list and matching global records outside it.

Retain original work, relationship, claim, locator, source and uncertainty objects, corpus order, parallel records and from/to orientation. Partition local records into matches and exclusions with all failed fields; separately partition matching records into local and outside. Counts refer to relationship records, not unique neighbors. No mutation, transitive expansion, neighbor-to-neighbor inclusion, source-date change or endpoint survey is part of this increment.

Technical acceptance requires exhaustive admitted field intersections in global and all-work scopes; count partitions; parallel/reversed records; empty and invalid cases; preserved source/claim identity; source-link and anchor coverage; equivalent JavaScript-off and native keyboard tasks; expanded axe checks; 1440/768/640/320 reflow and visual review; print/graphics-hidden/reduced-motion/forced-color access; zero client JavaScript and payload compliance. Preserve catalogue and incident-list baselines.

Before client filtering, compare this static route against an enhanced version using the same tasks, evidence placement and count definitions, with condition and case order counterbalanced. Record correctness, all material errors above, excluded-field identification, source-locator success, assistance and task time. Keep catalogue lookup as a separate navigation baseline. Publish only consented anonymized aggregate findings with sample, procedure and limitations. Faster lookup cannot offset worse factual interpretation. No learner study has been conducted. Retain the static comparator if a filter adds misconceptions or no useful inspection advantage; any future controls must also pass the original atlas filter-state, keyboard, URL-recovery and performance gates.
